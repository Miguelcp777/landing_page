Install Base — single source of truth

Data work

03

Contract Profitability — ASP

Synthetic data · Figures obscured

Which maintenance contracts are actually profitable, and on which platforms and for which customers?

Data work
Bring contract, revenue and cost together into comparable metrics, including average sales price per contract type.
What it changed
The ASP analysis is used to reprice maintenance contracts: it shows which contract types return least against their cost, by platform and by customer. A companion dashboard flags contracts approaching renewal for the sales team.
